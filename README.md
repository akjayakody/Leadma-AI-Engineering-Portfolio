## Selected projects

### 1. Leadma AI Workforce — Agentic AI platform
An enterprise-oriented platform concept and implementation for managing AI-assisted project delivery: project isolation, task orchestration, specialist-agent workflows, approval gates, knowledge retrieval, support workflows, budget controls, auditability, and operational reporting.

- Stack documented in repository: NestJS, Next.js, TypeScript, Prisma, PostgreSQL; Docker Compose includes PostgreSQL/pgvector, Redis and MinIO.
- Engineering evidence documented: 130 automated tests across five suites.
- Important limitations: the acceptance report identifies a deterministic mock planner/agent provider; Claude adapter is unverified; no external GitHub/CI integration; containers not built; external penetration testing and realistic-scale load testing not completed.
- Private source repository: https://github.com/akjayakody/Leadma_AI_Agents
- Detailed summary: [case study](case-studies/leadma-ai-workforce.md)

### 2. Romaca ERP — Embroidery manufacturing operations
A working prototype for embroidery manufacturing, covering the flow from sample and costing through orders, receiving, production, quality control, finished goods, dispatch and invoicing.

- Stack documented in repository: React 19, TypeScript, Tailwind, Express, PostgreSQL, Prisma, Firebase Authentication emulator and Docker.
- Documented features include costing and quotation controls, purchasing and three-way invoice matching, inventory, production planning, double-entry finance, HR/payroll workflows, maintenance, QC and reporting.
- Repository documents 67 automated tests for the prototype.
- Important limitation: authentication is configured with the Firebase emulator; production Firebase configuration and go-live preparation remain necessary.
- Private source repository: https://github.com/akjayakody/romaka-erp
- Detailed summary: [case study](case-studies/romaca-erp.md)

### 3. Leadma Audit — ISO 45001 ergonomic audit platform
A web application for managing ergonomic audit engagements from auditor assignment and field observations to reports, corrective actions, invoices and certificate verification.

- Stack documented in repository: React, Vite, Express, Prisma and PostgreSQL.
- Documented controls include server-side role enforcement, two-step sign-in, revocable sessions, signed-report locking, non-repeating document numbers and client-level data separation.
- Private source repository: https://github.com/akjayakody/leadma-audit-platform
- Detailed summary: [case study](case-studies/leadma-audit.md)

### 4. LeadmaIE — Industrial engineering and workforce operations
A factory-focused application covering floor control, machine breakdowns and changeovers, plant layouts, workforce and skills, order capacity, deviation action plans and rules-driven payroll.

- Stack documented in repository: JavaScript, Node.js, PostgreSQL for deployment and SQLite for local use.
- Repository documents role separation across HR, payroll, approver, finance, industrial engineering and maintenance.
- Private source repository: https://github.com/akjayakody/LeadmaIE
- Detailed summary: [case study](case-studies/leadmaie.md)

## Engineering approach

Across these projects, the documented design principles include:

- Enforce business rules on the server, not only in the user interface.
- Apply role-based access controls to sensitive operations.
- Preserve audit trails for important business transactions.
- Use approval gates for high-impact actions.
- Protect tenant, project, customer and company data boundaries.
- Use automated tests to verify critical business rules and failure paths.
- Keep operational limitations and deployment readiness visible.
