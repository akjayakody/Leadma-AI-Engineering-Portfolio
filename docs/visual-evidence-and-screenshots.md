# Visual Evidence and Screenshots

## Current status

The private Leadma AI Workforce repository contains UI evidence images under:

`docs/evidence/live-command-centre/`

The filenames indicate examples of working agents, dependency waits, approval-required states, completed and failed runs, project switching/isolation, refresh recovery and a mobile-width view.

The private repository also contains blueprint/infographic assets. These assets have **not** been copied into this public portfolio.

## Why screenshots are not published yet

The images are in a private implementation repository and may expose internal product details, test data, workflow states or unfinished UI. They should be reviewed by the project owner before public release. This portfolio therefore does not reproduce them or imply that the screenshots are approved for public distribution.

## Recommended public evidence pack

After review, select a small set of clean, non-sensitive images:
1. Leadma AI Workforce — main command-centre dashboard.
2. Leadma AI Workforce — approval-required workflow.
3. Leadma AI Workforce — project isolation view, with all names and data anonymised.
4. Romaca ERP — one representative production or inventory screen.
5. Leadma Audit — one audit observation/report screen.
6. LeadmaIE — one factory floor or capacity-planning screen.

Before adding any image:
- remove personal, client and supplier data;
- remove email addresses, IDs, tokens, URLs and credentials;
- verify that the screen reflects the current application;
- obtain any required client or stakeholder permission;
- add a short caption stating what the screenshot demonstrates.
