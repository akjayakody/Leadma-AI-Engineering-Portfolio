# Case Study: LeadmaIE

## Overview
LeadmaIE is an industrial engineering application for apparel manufacturing environments.

## Capabilities documented
- Factory floor control, machine breakdowns and changeovers.
- Plant layouts by production style.
- Workforce and skills management.
- Order coverage and open-capacity planning.
- Deviation action plans.
- Rules-driven payroll workflows.
- Attendance, rotating rosters, meal scans and payroll controls.

## Technology
Plain JavaScript, Node.js, PostgreSQL for deployment and SQLite for local development/testing.

## Role separation documented
The README describes separate access scopes for HR, payroll maker, approver, finance, industrial engineering and maintenance roles.

## Portfolio relevance
This project demonstrates domain-focused software design for factory operations and the integration of industrial engineering, workforce management and payroll processes.
